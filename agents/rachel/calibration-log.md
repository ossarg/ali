# Calibration Log — Predicciones y Outcomes

_Antes de clasificar un mail ambiguo o tomar una decisión significativa, registro la predicción. Después anoto el outcome real. Con el tiempo, los patrones de sesgo del clasificador se vuelven visibles._

## Formato
```
### [FECHA] — [Descripción del mail o decisión]
**Predicción:** <qué tipo de evento creo que es / qué datos extraí>
**Incertidumbre:** <dónde podría estar equivocado>
**Confidence:** Alta / Media / Baja

**Outcome:** [completar cuando se confirme]
**Delta:** [qué me sorprendió]
**Lección:** [qué actualizar en el clasificador o en las reglas]
```
